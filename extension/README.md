# Diecast Hunter — Browser Extension

Browser extension for capturing Facebook Marketplace listings into the
Diecast Hunter desktop app. Manifest V3; works in Firefox 121+ and any
recent Chromium browser (Chrome, Edge, Brave, etc.).

## How it works

1. Open a Facebook Marketplace item page
   (`https://www.facebook.com/marketplace/item/<id>/`).
2. Click the Diecast Hunter extension icon.
3. The popup extracts the listing's OpenGraph metadata
   (title, image, price, URL, description) and shows a preview.
4. Click **Save to Diecast Hunter** to POST the data to the desktop app's
   localhost listing-receiver. The listing appears on the
   *Saved Listings* page and runs through the matcher automatically.

The extension does not collect any data beyond what the user explicitly
chooses to save, and only contacts the desktop app on `localhost`. No data
leaves the user's machine.

## Setup

The desktop app exposes a small HTTP server on `127.0.0.1:17381`. The
extension needs that URL plus a shared secret (auto-generated by the
desktop app).

1. Open the desktop app → **Settings** → **Browser-extension receiver**.
2. Copy the **Endpoint URL** (e.g. `http://localhost:17381/listings/save`)
   and the **Shared secret** (click *Show* / *Copy*).
3. Install the extension (see below), open its options, paste both values,
   click **Save**. The page health-checks the endpoint immediately so you
   know whether the connection works.

## Install — Firefox (temporary, for development)

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…**
3. Select `extension/manifest.json` from this repo.
4. The extension stays loaded until you restart Firefox. To install
   permanently, sign and submit to AMO, or use a Firefox Developer Edition
   / Nightly with `xpinstall.signatures.required` set to `false`.

## Install — Chrome / Edge

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode** (top-right toggle).
3. Click **Load unpacked**.
4. Select the `extension/` directory from this repo.

## What gets sent to the desktop app

```json
{
  "external_id": "123456789012",
  "url": "https://www.facebook.com/marketplace/item/123456789012/",
  "title": "2002 Jeff Gordon #24 Pepsi Daytona 1:24 Action ARC",
  "price_cents": 4500,
  "currency": "USD",
  "image_url": "https://scontent.../l1024.jpg",
  "description": "Mint condition, original box…",
  "seller_username": null,
  "location": null
}
```

`seller_username` and `location` are placeholders for v1 — extracting them
reliably from FB's React-rendered DOM requires more brittle scraping than
the OpenGraph approach, so they're left null until needed.
